# 바람숲

숨 고르기, 짧은 명상, 감각 산책과 몸 쉬기로 잠시 나를 돌보는 웹 쉼터입니다. 활동 내역이나 글을 저장하지 않습니다.

## 실행

`index.html`을 브라우저에서 직접 열면 바로 사용할 수 있습니다. 외부 패키지 설치는 필요 없습니다.

로컬 서버를 사용하려면 Node.js 20 이상에서 `node server.mjs`를 실행한 다음 http://localhost:3000 을 여세요. `npm run dev`도 같은 동작입니다. PowerShell에서 npm 스크립트 실행이 차단되면 `npm.cmd run dev`를 사용하세요. 3000번 포트를 사용 중이라면 PowerShell에서 `$env:PORT = '4173'`을 설정한 뒤 실행하고 http://localhost:4173 을 여세요.

## 동작

- 기분을 선택하고 자유롭게 글을 씁니다. 기분 선택은 선택 사항입니다.
- 선택한 기분에 따라 아침 안개·비 오는 오후·별이 뜬 밤으로 숲 풍경이 바뀝니다. 풍경은 직접 선택할 수도 있습니다.
- ‘다른 질문’은 새 글감을 보여 줍니다. 이미 쓴 내용은 바꾸지 않습니다.
- **숨 고르기**: 1·3·5분 중 시간을 골라 4초 들이쉬기·6초 내쉬기를 안내합니다. 숫자가 부담스러우면 호흡 속도나 원의 움직임을 강요하지 않는 ‘자연 호흡’을 선택할 수 있습니다.
- **고요히 머물기**: 기본 3분, 1·3·5분 중 선택할 수 있습니다. 알아차리기·호흡에 머물기·주의 넓히기의 세 단계로 안내합니다. 음성 안내는 없습니다.
- **지금 여기 산책**: 시각·촉각·청각·향·맛을 순서대로 살피며 직접 다음 단계로 넘깁니다. 찾기 어려운 감각은 건너뛰어도 됩니다.
- **몸에 쉼 건네기**: 어깨·손·얼굴·발·온몸의 감각을 편한 만큼 알아차리고 직접 다음 단계로 넘깁니다.
- 모든 활동은 일시정지·재개·조기 종료할 수 있습니다. 다른 활동을 고르면 진행 중인 활동은 종료되고 새 활동을 시작할 준비 상태가 됩니다.
- 집중 화면은 현재 활동만 보여 줍니다. 돌아가기 버튼이나 Escape로 나오며 진행 상태를 유지합니다.
- 다른 탭이나 앱을 보러 가면 활동을 일시정지하고 소리를 끕니다. 돌아온 뒤 직접 재개할 수 있습니다. 새로고침과 페이지 이동 시 활동은 초기화됩니다.
- 글쓰기는 필요할 때 펼치는 공간으로 제공합니다. 활동을 바꿔도 작성 중인 글을 지우지 않습니다.
- ‘바람에 흘려보내기’를 누르면 글과 기분을 즉시 지우고 짧은 전환 효과를 보여 줍니다.
- 글 대신 장식용 나뭇잎만 잠시 떠다니다 사라집니다. 나뭇잎에는 쓴 내용이 들어가지 않습니다. 모션 줄이기 설정에서는 나뭇잎 효과를 생략합니다.
- 새로고침, 페이지 이동, 뒤로 가기로 복원된 페이지에서도 초안을 비웁니다.
- 글과 기분은 현재 페이지의 메모리에서만 사용합니다. 서버 전송, 쿠키, localStorage, sessionStorage, IndexedDB, 분석 도구를 사용하지 않습니다. 글 복구 기능은 없습니다.
- 배경 소리는 외부 녹음 없이 Web Audio로 합성한 바람·비·시냇물입니다. 상단과 소리 패널의 버튼으로 켜고 끄며 음량을 조절할 수 있습니다. 소리를 켜기 전에는 재생하지 않습니다.
- 모바일 화면, 키보드 조작, 모션 줄이기 설정을 지원합니다.
- 활동별 ‘근거와 안내’ 및 자료실에 논문, 기관 자료, 공식 게시 페이지로 출처를 확인한 YouTube 설명을 연결합니다. 외부 영상은 자동으로 불러오지 않습니다.
- 완료 또는 조기 종료 후 느낌을 선택할 수 있습니다. 선택은 기록하지 않으며, ‘오히려 불편해요’를 선택하면 소리를 끄고 편한 호흡과 주변 감각으로 돌아오는 안내를 표시합니다.

`npm run check`로 JavaScript 문법을 검사할 수 있습니다. 로컬 서버는 정적 파일만 제공하고 요청을 기록하지 않습니다.

## 근거와 검증

자료별 연구 조건, 앱의 적용 범위와 한계, 영상 출처의 확인 방법은 [EVIDENCE.md](EVIDENCE.md)에 정리했습니다. 전문가 감수나 앱 자체의 임상시험을 거쳤다는 뜻은 아닙니다.

브라우저 회귀 검사는 Python의 Playwright로 실행합니다. 개발용 환경에 `python -m pip install playwright`와 `python -m playwright install chromium`으로 준비한 뒤 `python -m unittest discover -s tests -v`를 실행하세요. 이미 설치된 Edge를 사용하려면 PowerShell에서 `$env:FOREST_BROWSER_CHANNEL = 'msedge'`를 설정하면 됩니다. 실행 시 사용 가능한 임시 포트의 로컬 서버를 열고 검사 종료 시 닫습니다.

검사 범위: 호흡 속도·연습 시간, 타이머 일시정지·완료, 세 단계 명상, 감각·몸 쉬기, 집중 화면, 소리 조작, 화면 비활성 시 정지, 출처 연결, 모바일 가로 넘침, 모션 줄이기, 초안 삭제 및 외부 요청·저장소 사용 여부.
